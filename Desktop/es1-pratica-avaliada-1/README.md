# Prática Avaliada 1 - Engenharia de Software 1 Felipe Tavares

Este repositório contém a entrega da Prática Avaliada 1, simulando a estruturação ágil para a startup fictícia **AgileTech Solutions**.

## Estrutura do Repositório

* `analise-processo.md`: Análise sobre o Manifesto Ágil, dificuldades de Brooks e adoção de práticas na empresa.
* `processo-xp-scrum.md`: Definição de práticas de XP, fluxo Scrum, cerimônias e cronograma.
* `analise-yagni.md`: Documentação das violações do princípio de Design Simples.
* `src/usuario_simples.py`: Código refatorado focado exclusivamente nos requisitos atuais.

## Contexto do Projeto

Foi proposto melhorar o fluxo de trabalho de uma equipe composta por 5 desenvolvedores e 1 Product Owner, migrando a organização para um modelo híbrido utilizando **Scrum e Extreme Programming (XP)**. Adicionalmente, foi feita a refatoração de um código escrito em Python para adequá-lo ao princípio **YAGNI** (You Aren't Gonna Need It).

## Como Visualizar

A documentação pode ser lida diretamente pelo GitHub clicando nos arquivos `.md` listados acima. O quadro de tarefas (Kanban) encontra-se na aba **Projects** deste repositório.
